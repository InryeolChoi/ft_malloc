# ft_malloc
[English version](README.en.md)

`ft_malloc`는 C로 `malloc`, `free`, `realloc` 동작을 직접 구현하기 위한 메모리 할당자 프로젝트입니다.

## 목표

- 동적 메모리 할당기의 기본 구조를 이해합니다.
- 할당 블록의 메타데이터를 관리합니다.
- 시스템 메모리와 사용자 요청 크기 사이의 흐름을 직접 다룹니다.

## 현재 구성

- `new.h`: 메모리 블록 메타데이터 구조체 정의
- `new.c`: 구현 파일
- `Makefile`: 빌드 규칙 작성 예정

## 진행 상태

현재는 프로젝트 초기 설정 단계입니다. 이후 메모리 영역 관리, 블록 분할 및 병합, 할당/해제 API 구현을 순서대로 추가할 예정입니다.
